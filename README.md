# Trabajo de Repaso III - POO

Ejercicios de herencia y sobrescritura de métodos en Java.

- `punto1/`: MaterialDigital, LibroDigital y Audiolibro (`@Override` de `mostrarDescripcion()`).

```
cd punto1
javac *.java
java Main
```

Lo mismo dentro de `punto2/`.
